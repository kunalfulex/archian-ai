# Security Policy

## Supported versions

Security fixes are applied to the latest release on `main` of this repository.

## Reporting a vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Email **security@archian.ai** with:

- A description of the issue
- Steps to reproduce (or a proof of concept)
- Affected version / commit if known
- Your preferred contact for follow-up

We aim to acknowledge reports within a few business days. If the report is accepted, we will coordinate a fix and disclosure timeline with you.

## Scope

In scope: the Archian AI community edition in this repository (backend API, web UI, connectors for file/SQL/Salesforce/Google Sheets).

Out of scope: third-party services (Stripe, Salesforce, Google, OpenAI, etc.), and the private hosted billing package (`archian-cloud`) which is not part of this public tree.
